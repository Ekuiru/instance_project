# Разработка системы сегментации объектов морской сцены на основе YOLO

## Постановка задачи
Рассказать про предметную область

Цель работы — разработать и исследовать систему **instance-сегментации** для обнаружения объектов в морской среде (лодки, люди, буи) на изображениях и видео.  
Задача актуальна для мониторинга акваторий: безопасности, спасательных операций и автономных судов.

Морская сцена усложняет компьютерное зрение из‑за:
- мелких объектов (например, swimmer)
- сильного дисбаланса классов
- отражений и шума воды
- перекрытия объектов

## Почему segmentation, а не detection

Классический object detection с bounding boxes недостаточен, так как:
- не даёт точных границ объектов
- хуже работает при частичном перекрытии
- не предоставляет информации о форме объекта

👉 Поэтому выбирается задача **instance segmentation**, позволяющая выделять каждый объект с точными пиксельными границами.

## Выбор модели: YOLO

В качестве базовой модели используется YOLO, потому что она:
- обеспечивает высокую скорость работы (важно для видео)
- показывает хорошие результаты на малых объектах
- поддерживает задачу instance segmentation
- удобна для практического применения и экспериментов

🔥 Основная идея курсовой — сравнение разных инстанс сегментейшн моделей

## Результаты и анализ ошибок

В качестве результатов предполагается показать:
- метрики: `mAP box`, `mAP seg`, `recall`, `precision`
- визуализации предсказанных масок
- анализ по классам: какие работают хуже и почему

Примеры важных наблюдений:
- низкое качество сегментации класса `float` из‑за малого числа обучающих примеров
- ошибки для `animal` из‑за малого размера объекта и слабого контраста с водой

Такой анализ ошибок подчёркивает не только качество модели, но и глубину понимания её ограничений и условий применения.
